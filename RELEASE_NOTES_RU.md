# Software Hub v0.7.3 Stable 🚀

Портативное приложение для Windows 11 x64 на **Tauri 2 / Rust** с каталогом **126 карточек: 86 программ и 40 сайтов**.

## Возможности

- Удобный каталог программ и сайтов, поиск, категории и пагинация.
- Ссылки на официальные загрузки и дополнительные источники.
- Проверка доступных версий с локальным кэшированием, диагностикой и защитой от сетевых ошибок.
- Тёмный интерфейс Cinema Mono, мягкие фиолетово-розовые акценты, анимированные частицы.
- Настраиваемая локальная портативная папка данных.

## Изменения версии 0.7.3

- Доработана заставка запуска: название остаётся видимым примерно 1,8 секунды после готовности каталога и затем плавно исчезает.
- Каталог, Rust backend, правила проверки версий и основные элементы интерфейса относительно принятой v0.7.2 Stable не менялись.

## Установка

1. Скачайте `Software_Hub_v0.7.3_Stable_Portable.zip` из **Assets**.
2. Распакуйте содержимое в отдельную папку.
3. Запустите `SoftwareHub.exe` рядом с `portable-data`.

Для работы требуется **Microsoft WebView2 Runtime**. Отдельный установщик не нужен.
