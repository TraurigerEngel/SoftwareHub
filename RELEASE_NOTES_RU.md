# Software Hub v0.7.4 Stable — Security & Manual Refresh 💜

Новый стабильный выпуск для **Windows 11 x64**, на базе подтверждённой v0.7.3. Используется **Tauri 2 / Rust**, portable-формат без установщика.

## Что нового

- **Проверка версий только вручную.** Приложение не выполняет автоматическую проверку при запуске и не запускает отложенную фоновую проверку. Чтобы получить новые версии, нажмите «Обновить версии».
- **Сохранённые версии показываются сразу после открытия** из локального кеша; для просмотра не нужен сетевой запрос.
- **Исправления безопасности TLS (eMudhra)**: Rust-зависимости `rustls-webpki` 0.103.16 и `webpki-roots` 1.0.10 включены в новую сборку.
- **WinSCP:** проверка версии переведена на официальную страницу истории выпусков; оригинальная ссылка скачивания сохранена. При сетевой ошибке резервная версия 6.7 помечается как резервная, а не как подтверждённая.
- Сохранены **126 карточек** (86 программ, 40 сайтов), поиск, фильтры, оформление Cinema Mono, анимация и портативное хранение данных.

## Установка

1. Скачайте `Software_Hub_v0.7.4_Stable_Portable.zip` из Assets.
2. Распакуйте архив в отдельную папку. Запустите `SoftwareHub.exe`.
3. Для переноса собственных настроек скопируйте свою прежнюю папку `portable-data` **вручную**, предварительно создав резервную копию. В опубликованном ZIP она пустая.

Требуется Microsoft WebView2 Runtime. Автоматическое обновление приложения не предусмотрено.

## Проверка

Сборка публикуется после `npm run verify`, `cargo test --locked --lib`, Tauri Release и независимой проверки portable EXE и его SHA-256. Контрольные суммы ZIP-файлов приложены как `SHA256SUMS.txt`. Исполняемый файл не подписан цифровой подписью.

**Поддержка:** Windows 11 x64. **Источник:** https://github.com/TraurigerEngel/SoftwareHub

## Исправление отображения окна — Kinoteka HF51 Parity

- Вместо простой подгонки рабочей области используется проверенный нативный Win32-механизм из Kinoteka v1.2.1 Stable HF49/HF51.
- Windows определяет автоскрытие нижней панели задач через SHAppBarMessage. Только при автоскрытии программа временно выходит из maximized-режима, убирает невидимую неклиентскую рамку и выравнивается по реальным DWM-границам.
- Снизу остаётся 2 **физических** пикселя за пределами окна. Боковых зазоров быть не должно. Дополнительный A/B режим: SOFTWAREHUB_TASKBAR_GAP_PX=4.
- При фокусе или изменении геометрии коррекция повторяется; в обычном режиме панели задач окно остаётся развёрнутым.
- Публиковать только после реальной проверки вызова автоскрываемой панели задач на Windows 11.

## Исправление HF3 — без бело-голубой рамки Windows 11

- В конфигурацию главного Tauri-окна явно добавлено `"shadow": false` (как в Kinoteka v1.2.1 Stable).
- По умолчанию Tauri 2 может добавлять оконную тень и обводку даже при `"decorations": false`. Это проявлялось как светлая/акцентная полоса по бокам и снизу.
- Нативный механизм выравнивания, 2 физических пикселя свободного нижнего края, каталог и функции проверки версий не изменены.
- Реальный результат на Windows 11 требуется подтвердить до публикации v0.7.4.
