# Software Hub v0.7.5 Stable — Catalog Expansion

**Windows 11 x64 · Tauri 2 / Rust · Portable ZIP**

## Изменения относительно опубликованной v0.7.4

- Каталог увеличен с **126 до 141 карточки**: **92 программы и 49 сайтов**.
- Внесены обе пользовательские подборки от 11 ноября 2026 года (см. `CATALOG_UPDATE_RU.md`).
- Добавлены новые ресурсы в разделы ИИ, сеть, безопасность, система, разработка, Linux, дизайн и файлы.
- Для **Win11Debloat** и **LocalSend** подключена штатная проверка GitHub Releases только по нажатию **«Обновить версии»**.
- Сохранены существующие записи **ByeByeDPI** и **Node.js**; добавлены дополнительные адреса для **Webcam & Mic Test** и **RuTracker**, без дубликатов.
- В ходе тестирования до GitHub Release исправлены источники версий **ADB AppControl** (новый официальный домен) и **Snappy Driver Installer Origin** (актуальный формат `vN.N.N`, без устаревшего резерва `2.0.4`).
- Код окна, кэша и механизма версий Rust/JS, оформление Cinema Mono и portable-data не изменялись; в каталоге обновлена ссылка ADB AppControl.

## Установка

Скачайте `Software_Hub_v0.7.5_Stable_Portable.zip`, извлеките в отдельную папку и запустите `SoftwareHub.exe`.
Не распаковывайте поверх работающей v0.7.4. Для переноса пользовательского каталога/кэша вручную скопируйте нужные файлы из старой `portable-data` после резервного копирования.
Требуется Microsoft WebView2 Runtime. EXE не подписан цифровой подписью.

## Качество и проверка

Проект включает Node.js-тесты и Rust unit-тесты; Windows x64 EXE и архивы должны собираться и проверяться **на Windows 11** перед публикацией.
Итоги локальной сборки не заявляются до успешного выполнения `BUILD-ON-WINDOWS.ps1`.
Для ZIP релиза формируется файл `SHA256SUMS.txt`.
