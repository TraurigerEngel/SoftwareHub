# Software Hub v0.7.4 — конфиденциальность публикации

В публичную ветку GitHub отправляются только исходные файлы проекта, публичные описания, тесты и манифесты зависимостей. Не отправляются локальная `portable-data`, `node_modules`, `target`, `Release`, `Artifacts`, пользовательские конфигурации, `.env`, секреты, SQLite/DB, логи и кеши.

Portable ZIP содержит **пустую** `portable-data`. Пароли и пользовательские настройки не включаются. Перед отправкой скрипт проверяет содержимое staging-копии и отказывается работать при наличии подозрительных файлов или новых неожиданных корневых элементов.

Изначальная v0.7.3 Stable остаётся в истории GitHub и не перезаписывается. Новые исходники v0.7.4 отражают исправление безопасности и отключение автообновления версий.
