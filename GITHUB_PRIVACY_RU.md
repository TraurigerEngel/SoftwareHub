# Software Hub v0.7.5 — правила публикации

Репозиторий `TraurigerEngel/SoftwareHub` публичный. В GitHub отправляются только **разрешённые исходники** и документация, автоматически упакованные из белого списка.

Категорически нельзя публиковать: `portable-data`, личные настройки, кэши, `.env`, ключи, токены, логи, `node_modules`, `target`, временные файлы, базы данных и резервные копии.

Скрипт сборки создаёт portable-сборку с **пустой** папкой `portable-data`. Скрипт публикации берёт только проверенный ZIP исходников, а не всю рабочую директорию, и отказывается перезаписывать существующий GitHub Release или сдвигать чужую ветку.

Перед запуском скрипта публикации внимательно проверьте URL Check-Host с IP/портом: он входит в публичный `data/programs.json` каталога.
