# Software Hub — конфиденциальность при публикации 💜

В исходном пользовательском архиве версии v0.7.3 Stable нет рабочих SQLite-баз, персональных конфигураций или ключей. Для GitHub подготовлена копия **исходных файлов** без локального `portable-data`, кэшей, логов, `node_modules`, результатов сборок и бинарных web-шрифтов.

- `data/programs.json` и `data/sources.json` — штатный каталог Software Hub (126 карточек, 9 источников проверки версий).
- `portable-data/` создаётся рядом с приложением и остаётся на компьютере пользователя; не добавляйте его в Git.
- Секреты, `.env`, локальные настройки, отладочные логи и пользовательские файлы должны оставаться вне репозитория.
- Готовый `SoftwareHub.exe` не коммитится; для GitHub Releases используется отдельный проверенный Portable ZIP.
- Файлы Inter (`.woff2`) не публикуются в Git. Локальный `npm ci` устанавливает `@fontsource-variable/inter`, а `scripts/stage-fonts.cjs` штатно подготавливает необходимые ресурсы перед сборкой Tauri.
