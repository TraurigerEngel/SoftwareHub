# Software Hub 🚀

**v0.7.3 Stable** · Windows 11 x64 · Tauri 2 / Rust · Portable

**Software Hub** — каталог программ и полезных сайтов с поиском, фильтрацией, ссылками на официальные источники и проверкой доступных версий. Современный интерфейс *Cinema Mono* с фиолетово-розовыми акцентами, живыми частицами и собственной строкой заголовка.

[**Скачать Portable**](https://github.com/TraurigerEngel/SoftwareHub/releases) · [Описание v0.7.3](RELEASE_NOTES_RU.md) · [Безопасность данных](GITHUB_PRIVACY_RU.md) · [Проверки перед выпуском](RELEASE_CHECKLIST_RU.md)

## Возможности

- **126 карточек**: **86 программ и 40 сайтов** в подготовленном каталоге.
- Поиск по каталогу, фильтрация по категориям и страницам.
- Переходы на официальные страницы загрузки и другие проверенные ссылки.
- Проверка новых версий по поддерживаемым источникам с обработкой ошибок сети.
- Локальное кэширование результатов, ручная проверка и диагностический журнал.
- Портативная работа: личные настройки и кэш остаются на компьютере пользователя.
- Плавная заставка и интерфейс в стиле Cinema Mono, поддержка уменьшения анимаций.

## Установка (Windows 11)

1. Откройте [GitHub Releases](https://github.com/TraurigerEngel/SoftwareHub/releases).
2. После публикации скачайте **`Software_Hub_v0.7.3_Stable_Portable.zip`** в разделе **Assets**.
3. Распакуйте архив, сохранив структуру папок.
4. Запустите **`SoftwareHub.exe`** рядом с каталогом `portable-data`.

Установщик не нужен. Для работы необходим **Microsoft WebView2 Runtime**. **Не удаляйте `portable-data`** после настройки приложения: в ней могут храниться ваши настройки и кэш.

## Конфиденциальность

В GitHub опубликованы **только исходники**, без пользовательских файлов. Папка `portable-data`, логи, кэш, локальная конфигурация и временные результаты исключены правилами `.gitignore`.

- Каталог из `data/programs.json` содержит подготовленные карточки программ и сайтов, а не личные записи пользователя.
- Portable из релиза содержит **неизменённый оригинальный `SoftwareHub.exe`**, пустую папку данных и релизные метаданные.
- Не добавляйте в Git личные журналы или `portable-data` вручную.

Подробнее: [GITHUB_PRIVACY_RU.md](GITHUB_PRIVACY_RU.md).

## Проверка и сборка из исходников

Понадобятся **Node.js 22.13–22.x**, npm, **Rust** с инструментами **MSVC**, Windows SDK и зависимости Tauri 2. Команды ниже выполняйте в PowerShell из корня проекта:

```powershell
npm ci
npm run verify
cargo test --manifest-path .\src-tauri\Cargo.toml --locked --lib
.\MAKE-RELEASE.cmd
```

`npm ci` устанавливает, среди прочего, закреплённую зависимость Inter. Перед сборкой `scripts/stage-fonts.cjs` переносит нужные ресурсы в локальную папку `web/fonts/`. **Бинарные файлы шрифтов в GitHub не загружаются**, но при локальной сборке оригинальный шрифт подготавливается штатным способом.

Для полной упаковки исходная ветка содержит `MAKE-FINAL-ARCHIVES.ps1`. Выпуск нового EXE требует дополнительной проверки на Windows 11; предоставленный Portable — это **оригинальная стабильная сборка v0.7.3**, не пересобранная из GitHub-исходников.
